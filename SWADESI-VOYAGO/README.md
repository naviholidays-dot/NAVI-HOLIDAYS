# Swadesi Voyago website

This site is stored in the SWADESI-VOYAGO folder of the Navi Holidays repository so it remains separate from the main Navi Holidays website.

Website files: index.html, style.css, script.js, config.js.

Before enquiries are activated, update the WhatsApp number and email in config.js. This folder can be served from GitHub Pages as a subpath if Pages is enabled for the repository.
